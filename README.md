# DisasterSense AI

An AI-powered Disaster Intelligence Platform that detects disaster-related text using DistilBERT, extracts affected locations, and visualizes incidents on an interactive map.

## Features

- Disaster Detection using DistilBERT
- Confidence Score
- Interactive Map
- CSV Upload
- Manual Text Prediction
- REST API (FastAPI)
- Responsive Web Interface

## Tech Stack

- Python
- PyTorch
- Hugging Face Transformers
- FastAPI
- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap
